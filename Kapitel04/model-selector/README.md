# Kapitel 4: Modelle verstehen und auswählen

## Beispielcode

Dieses Kapitel enthält Utilities zur Modellauswahl und -analyse.

## Dateien

- `model-benchmark.ts` - Benchmark-Script für Modellvergleiche
- `hardware-analyzer.ts` - Analysiert verfügbare Hardware
- `model-router.ts` - Multi-Model-Router (Übung 5)

## Voraussetzungen

- Ollama installiert und läuft (Kapitel 3)
- Node.js 20+ oder Bun
- Mindestens 8 GB RAM

## Verwendung

```bash
cd Kapitel04/model-selector
npm install
npx tsx model-benchmark.ts
```

## Hinweis

Die vollständige Implementierung finden Sie im Buch.
Dieser Ordner enthält die lauffähigen Beispiele.
